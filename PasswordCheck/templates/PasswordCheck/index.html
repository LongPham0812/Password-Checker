How It Works

  • Enter a password into the text field. The password can be up to 30 characters and can include any character on the keyboard.
  • Check the boxes below the text field if the corresponding statements apply to the password (if you've used the password before or if the password contains any personal information).
  • Click the "Check Password" button. The password will be evaluated against the criteria below and given a score based on how strong and unique it is.
  • The results will be displayed on a new page. There will also be a list of strengths and weaknesses associated with the password so as to provide feedback.
  • Click the "Check Another Password" button to try another password or improve upon the current password.
  • Passwords entered on this website are not saved or used for any purposes other than evaluation.

Criteria

  • The password is of sufficient length (10 characters or longer, 30 characters maximum)
  • The password contains at least 1 uppercase letter (A-Z)
  • The password contains at least 1 lowercase letter (a-z)
  • The password contains at least 1 number (0-9)
  • The password contains at least 1 special character (!, @, #, etc.)
  • The password does not contain common words or phrases
  • The password is new and has not been used previously
  • The password does not contain personal information (username, date of birth, etc.)
  • The password contains a large variety of uppercase letters, lowercase letters, numbers, and special characters
